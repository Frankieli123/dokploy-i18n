# v0.28.3

## 状态
- 优先级：中
- 状态：已审查 / 部分吸收
- 对应范围：`v0.28.2 -> v0.28.3`

## 上游来源
- Release: https://github.com/Dokploy/dokploy/releases/tag/v0.28.3
- Compare: https://github.com/Dokploy/dokploy/compare/v0.28.2...v0.28.3

## 上游实际变更
这版开始有明确的新功能块，主要分成 5 类：

1. 全局 Search 能力扩展
   - 多个 router 增加 `search`
   - Command 搜索入口与侧边栏增加 `Deployments`
2. Deployment Dashboard / Queue
   - 新增集中式部署列表页
   - 新增队列查看能力
3. Project / Environment 查询结构调整
   - `project.all / environment.one` 改成更轻量字段选择
   - 补充 `allForPermissions`
   - project 响应里显式带项目名等列
4. Requests 展示优化
   - 状态码 `0 -> N/A`
   - 执行时间改成 `µs / ms / s` 自适应显示
5. 若干小修
   - Service card 行为修复
   - `duplicateEnvironment` 保留 `env`
