## 上游实际变更
这版变化较大，核心分成 5 类：

1. custom roles / audit logs / enterprise 权限体系继续深化
2. volume backups / web-server backup 稳定性修复
3. `mechanizeDockerContainer` 的可选 authConfig 修复
4. 数据库 `dockerImage` 字段更新容错
5. sidebar / watch paths / 通知展示等 UI 小修
