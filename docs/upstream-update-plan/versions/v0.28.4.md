# v0.28.4

## 状态
- 优先级：高
- 状态：已审查 / 部分吸收
- 对应范围：`v0.28.3 -> v0.28.4`

## 上游来源
- Release: https://github.com/Dokploy/dokploy/releases/tag/v0.28.4
- Compare: https://github.com/Dokploy/dokploy/compare/v0.28.3...v0.28.4

## 上游实际变更
这版核心集中在 6 类：

1. rollback 前增加 docker login
2. web-server backup 遇到特殊文件/设备文件时 rsync 失败修复
3. preview deployments 不再继承 `www` redirect middleware
4. Docker 客户端增加 `DOCKER_API_VERSION / DOCKER_HOST / DOCKER_PORT`
5. organization active 查询与前端 active organization 读取改造
6. mount / GitHub provider / invitation / schema 小修
