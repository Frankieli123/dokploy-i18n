## 上游实际变更
这版仍然偏小，核心集中在 5 类：

1. GitHub Provider 初始化时对 `organizationId/userId` 增加空值保护
2. Compose domain 写回逻辑去掉“无 domain 时直接跳过”的前置返回
3. `trustedOrigins` 查询与缓存优化
4. `BreadcrumbSidebar` 删除调试日志
5. app 侧数据库连接与测试补充

## 本地审查结论

### 已吸收
#### 1. GitHub Provider 空值保护
已落地：
- `apps/dokploy/components/dashboard/settings/git/github/add-github-provider.tsx`

吸收内容：

### 已覆盖
#### 2. Compose domain handling
上游改动文件：
- `packages/server/src/utils/docker/domain.ts`

上游核心意图：
- 即使 `domains.length === 0`，也继续走 compose 读写逻辑
- 避免在某些 compose/domain 场景下保留旧的 Traefik 标签

本地现状：
- 本地该文件已经做了更大范围的 domain/Traefik 标签治理
- `writeDomainsToCompose()` 当前也没有“无 domain 直接 return”的旧逻辑
- 本地实现已经超出 v0.28.2 的修复范围

结论：
- 上游这部分 **已被本地更完整方案覆盖**
- 无需再单独吸收
