# v0.28.6

## 状态
- 优先级：中
- 状态：已审查 / 部分吸收
- 对应范围：`v0.28.5 -> v0.28.6`

## 上游来源
- Release: https://github.com/Dokploy/dokploy/releases/tag/v0.28.6
- Compare: https://github.com/Dokploy/dokploy/compare/v0.28.5...v0.28.6

## 上游实际变更
这版主要分两类：

1. 大块：whitelabeling / enterprise 相关
2. 通用项：
   - Docker 配置环境变量改成 `DOKPLOY_*`
   - GitHub preview deployment 支持 `labeled`
   - deployment webhook URL 支持点击复制
   - code editor 恢复搜索并支持 CSS
   - 多处 session / active organization 读取链继续统一

## 本地审查结论

### 已吸收
#### 1. Docker 配置环境变量改名
已落地：
- `packages/server/src/constants/index.ts`

吸收内容：
- 支持 upstream 的：
  - `DOKPLOY_DOCKER_API_VERSION`
  - `DOKPLOY_DOCKER_HOST`
  - `DOKPLOY_DOCKER_PORT`
- 同时兼容本地已有旧变量名

结论：
- 结构继续向 upstream 靠拢
- 不破坏现有部署环境

#### 2. code editor 搜索 + CSS 支持
已落地：
- `apps/dokploy/components/shared/code-editor.tsx`

吸收内容：
- 保留编辑器内搜索能力
- 增加 `css` 语言支持

结论：
- 低风险 UX/编辑体验增强
- 已直接吸收

#### 3. webhook URL 点击复制
已落地：
- `apps/dokploy/components/dashboard/application/deployments/show-deployments.tsx`

吸收内容：
- webhook URL 变成可点击复制
- 更接近 upstream 交互

结论：
- 低风险 UX 修复
- 已直接吸收

#### 4. session / active organization 读取统一
已落地：
- `apps/dokploy/components/layouts/side.tsx`
- `apps/dokploy/components/dashboard/search-command.tsx`

吸收内容：
- 进一步使用 `api.user.session.useQuery()`
- `activeOrganization` 继续走 `api.organization.active`

结论：
- 继续减少对旧 authClient 读取链的依赖
- 已直接吸收

### 已覆盖 / 无需再吸收
#### 5. GitHub `labeled` action
上游涉及：
- `apps/dokploy/pages/api/deploy/github.ts`

本地现状：
- 本地当前已经支持 `labeled / unlabeled`
- preview deployment 创建与标签检查逻辑已覆盖这类事件

结论：
- 已覆盖

### 明确跳过
#### 6. whitelabeling / enterprise 大块
上游涉及：
- `components/proprietary/whitelabeling/*`
- `routers/proprietary/whitelabeling.ts`
- `webServerSettings` whitelabelingConfig

原因：
- 这是 enterprise / branding 专题
- 不属于当前版本线里“通用项同步”

结论：
- 明确跳过
