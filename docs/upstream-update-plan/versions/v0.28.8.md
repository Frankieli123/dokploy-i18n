## 上游实际变更
这版非常集中，核心就是 API Key：

1. `apikey` schema 从 `user_id` 改成 `config_id + reference_id`
2. better-auth `apiKey({ references: "user" })` 对齐
3. API Key 删除鉴权从 `userId` 改成 `referenceId`
4. 创建 API Key 后 metadata 更新链路调整
