# v0.28.5

## 状态
- 优先级：高
- 状态：已审查 / 部分吸收
- 对应范围：`v0.28.4 -> v0.28.5`

## 上游来源
- Release: https://github.com/Dokploy/dokploy/releases/tag/v0.28.5
- Compare: https://github.com/Dokploy/dokploy/compare/v0.28.4...v0.28.5

## 上游实际变更
这版核心分成 7 类：

1. trustedOrigins 数据库异常容错
2. Azure OpenAI-compatible `/v1` 双重后缀修复
3. compose / yaml `maxAliasCount` 防资源耗尽
4. port conflict 检测增强
5. GitHub setup userId 透传、organization/session 读取调整
6. volume backup 通知容错、provider internal URL 优先
7. backup / restore / volume backup 路径改成带 `appName`

### 暂未直接吸收
#### 10. backup / restore / volume backup 路径带 `appName`
上游涉及：
- `packages/server/src/utils/backups/*`
- `packages/server/src/utils/restore/*`
- `packages/server/src/utils/volume-backups/*`

当前判断：
- 这会改变现有备份对象路径语义
- 与你们当前已增强的备份体系耦合较深
- 如果机械硬并，存在对现有备份可见性/恢复路径的影响

结论：
- 这是 **备份专题**
- 暂不机械硬并，需单独审

#### 11. rollback / deployment cleanup 深修
上游涉及：
- `packages/server/src/services/deployment.ts`
- `packages/server/src/services/rollbacks.ts`
- `packages/server/src/services/registry.ts`

当前判断：
- 这和本地 rollback / deployment 保留逻辑有一定耦合
- 值得做，但比本轮其他修复更像专题

结论：
- 暂列为后续专题项
